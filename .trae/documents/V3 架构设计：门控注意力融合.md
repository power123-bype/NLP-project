# V3 架构升级计划：引入注意力机制 (Attention Mechanism)

目前的 V2 双塔模型虽然解决了维度对齐问题，但图像和文本的融合依然是“硬拼接”。为了解决 `Forest Dark` 这种图像特征过于强势的问题，我们需要一种机制，让模型能根据文本指令动态地“关注”或“抑制”图像的某些特征。

## 核心设计：Gated Fusion (门控融合) 或 Attention
我们将在 V3 中引入 **Cross-Modal Attention (跨模态注意力)** 或 **Gated Residual Connection (门控残差)**。

考虑到数据量和模型复杂度，我推荐使用一个轻量级的 **Gated Fusion** 机制：
1.  **文本指导门控 (Text-Guided Gate)**：利用文本特征生成一个“门控信号” (Gate)，用来调节图像特征的通过率。
2.  **逻辑**：如果文本说“忽略原本的亮度”，门控机制可以学习去抑制图像特征中的亮度分量。
